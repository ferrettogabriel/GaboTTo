# GaboTTo

Portfolio personal de Gabriel Ferretto, desarrollado con React, TypeScript y Vite y publicado en Vercel.

## Desarrollo local

Requisito: Node.js.

1. Instalar dependencias: `npm ci`
2. Iniciar el servidor: `npm run dev`
3. Comprobar TypeScript: `npx tsc --noEmit`
4. Generar la versión de producción: `npm run build`

El portfolio no necesita variables de entorno ni una API key de Gemini.
